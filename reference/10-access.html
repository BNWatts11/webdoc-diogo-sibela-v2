00:00I come in from the dark and the chair is already there. I don't look at it yet. it has to feel like it was waiting, not placed
00:14Breath first. Everything slow. I rush the first lower — I rush the first lowering, every time. Slower.
[She lowers toward the seat; the chair holds her weight; her hand stays open.]
00:38Suspension on the inhale, then let the spine give. The chair is a partner, not a prop. tell Tânia: the pause at :41 wants to be longer
01:02Stillness. Long enough that someone in the room stops breathing with me.
[She is motionless on the chair; only the light moves.]
01:20Rise without using my hands. Leave the chair exactly as it was. That's the whole piece. what remains is the chair — that's the point
C · High contrast, re-imagined

Three lighting cues, not one “mode”.

A high-contrast setting doesn't have to look like an emergency. Treated as stage lighting, it becomes a deliberate scene the visitor chooses — and still passes the numbers.

Cue 1 · default

House warm

The lived stage — warm linen, low light, the everyday room.

Cue 2 · AAA

Silhouette

Pure black, white text, one amber spotlight. 21:1 contrast — the starkest lighting state.

Cue 3 · AAA

Cold wash

Deep teal-black with a cyan key — a cooler high-contrast scene for different eyes.

/* high contrast IS a lighting scene — swap the stage's variables, keep the layout */
html[data-scene="silhouette"]{
  --ink: #000;  --bone: #fff;            /* 21:1 — AAA */
  --kraft: #FFB54D;                        /* the single amber spotlight */
  --line-strong: rgba(255,255,255,.72);
}
html[data-scene="silhouette"] body{ background: #000; }      /* drop the warm wash */
html[data-scene="silhouette"] body::before{ opacity: 0; }    /* and the grain, for clarity */

// the console just sets the scene; every component re-lights from the variables
btn.onclick = () => document.documentElement.setAttribute('data-scene', btn.dataset.scene);
D · Principles

Designed in, never bolted on.

↳ 01

One door, not a side entrance

Access lives in the main interface — the same console everyone uses — so no visitor is sent to a lesser, separate version of the work.

↳ 02

The standards still hold

Under the art: semantic HTML, real aria-pressed controls, full keyboard paths, visible focus, and AA/AAA contrast in every scene. Beautiful and conformant.

↳ 03

Dignity over disclaimer

The transcript is offered as something worth reading, not an obligation. Captions and descriptions are written with the same care as the script.

↳ 04

The visitor sets the room

Lighting, motion, the described voice — each is a choice the person makes for themselves, remembered across the site, never assumed.
