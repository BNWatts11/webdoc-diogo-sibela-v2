Component · Video Framing

No rectangles.
The footage lives in the light.

A video player with hard corners would sit on top of this web doc like a window cut into the wall. Instead, the footage is a pool of spotlight on a dark stage — its edges dissolve into the room, broken by the soft shadows of boxes, fading where the light falls off. Built with CSS masks, clip-paths, and procedural vignettes; no images, no hard frame.

A · The signature treatment

A spotlight pool, breathing.

the edges aren't cropped — they fall off into the dark
B · Four ways to lose the rectangle

Each frame, a different falloff.

Spotlight poolradial mask

A radial mask fades the footage to nothing at the edges — a soft oval of light, no border.

Cast by boxesclip-path shadows

Soft box-shaped shadows fall across the frame from off-screen, breaking the edge as scenic props would.

Hand-cut apertureirregular clip-path

A slightly off, asymmetric clip-path — a gap between flats — with an inset vignette feathering the cut.

Torn dissolveSVG turbulence mask

An SVG mask whose edge is displaced by noise and blurred — an organic, analog falloff, never a clean line.

C · Implementation guide

How the edges dissolve.

The container's background is the stage itself, so wherever the mask reaches zero the video simply becomes the room. The two core moves:

/* 1 · spotlight pool — the footage fades to nothing at its edges */
.stage-video video{
  -webkit-mask-image: radial-gradient(56% 70% at 50% 46%, #000 36%, transparent 82%);
          mask-image: radial-gradient(56% 70% at 50% 46%, #000 36%, transparent 82%);
}                                  /* black = keep, transparent = dissolve into stage */

/* 2 · torn, analog edge — an SVG mask displaced by noise, then blurred */
.stage-video.torn video{
  mask-image: url("data:image/svg+xml, … feTurbulence + feDisplacementMap + feGaussianBlur …");
  mask-size: cover; mask-repeat: no-repeat;
}

/* 3 · shadows of boxes falling across the frame */
.stage-video .shadow b{
  position: absolute; background: linear-gradient(180deg, rgba(8,6,4,.92), transparent);
  clip-path: polygon(0 0, 86% 6%, 72% 96%, 0 84%);  /* a box silhouette */
  filter: blur(7px);                              /* soft, like a real cast shadow */
}

/* the actual markup — ambient footage, no chrome */
<div class="stage-video torn">
  <video src="diogo-solo.mp4" muted loop autoplay playsinline
         poster="diogo-still-charcoal.jpg"></video>
</div>

Use -webkit-mask-* alongside the unprefixed properties for Safari. The poster is a charcoal still from the mood board, so the frame reads on the stage even before play.

D · Framing principles

Alive, analog, integrated.

↳ 01

The background is the frame

No borders, no cards. The container shares the stage's colour, so masked edges become the room — seamless, not pasted on.

↳ 02

Light breathes

The spotlight vignette drifts and swells on a slow cycle, so the pool feels lit by a living source rather than a static gradient.

↳ 03

Gentle masks for content, strong for atmosphere

Primary footage with information keeps a softer vignette so nothing important is cropped; ambient clips can dissolve hard.

↳ 04

Accessible underneath

Real players keep captions and controls; masking is purely visual. prefers-reduced-motion stills the breathing and drift.
