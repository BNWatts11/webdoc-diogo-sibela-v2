Component · Navigation Concept

The spine —
nine stops, nine boxes.

The chapter markers aren't slider dots. Each is a flattened cardboard box — slightly imperfect, asymmetrical, no two alike — that leans and settles under its own weight when you reach for it. Hover or focus a box; use arrow keys to move along the thread.

On the motion
01

Weighted, not snappy

Transitions run long (~0.85s) on a slow-to-gather, slow-to-settle curve, so a box feels like it has mass rather than a UI state flipping.

02

It leans, it doesn't bounce

On hover the box tilts and skews a little — like cardboard taking weight — then settles. No spring, no overshoot, nothing that reads as computed.

03

Imperfect by design

Each marker is a hand-cut polygon, no two identical, with a faint corrugation grain. The thread is soft-blurred, not a crisp 1-pixel line.
