Naming convention & folders

One rule, so nothing gets lost.

File naming

IDWD_[SECTION]_[type]_[slug]_v[NN].[ext]
  IDWD_DIGOO_solo_boxes_master_v01.mp4
  IDWD_SIBELA_portrait_intro_v02.mp4
  IDWD_OBJ_chair_360_v01.glb

Section codes — CONCEPT · DCD · TANIA · DIGOO · SIBELA · PROCESS · SB · PERF · OBJ · POST · A11Y · BRAND · LEGAL. Version numbers always two digits. Master files keep their original name forever; only copies get re-versioned.

/assets/  — one folder per section code (masters, untouched)
