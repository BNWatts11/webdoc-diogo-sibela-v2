Component · Sound Concept

The room has a sound,
and it's almost silence.

No clicks, no beeps, no UI chimes. The interface speaks in the materials of the stage — the soft drag of a cardboard box, the rustle of a costume, a quiet breath. Sounds are off until you ask for them, gentle by design, and they answer to your pace: linger, and the room responds; rush, and it stays quiet.

C · Implementation guide

How it's built.

One gentle master chain, procedural generators per material, and a pace function that decides how much sound a gesture earns. This is the core of what's running on this page.

// one gentle master chain — low gain, soft top end, a limiter
master = ctx.createGain();                 master.gain.value = 0;
const soft = ctx.createBiquadFilter();    soft.type = 'lowpass'; soft.frequency.value = 5200;
const comp = ctx.createDynamicsCompressor(); // keeps everything gentle, never harsh
master.connect(soft).connect(comp).connect(ctx.destination);

// the soft drag of cardboard — filtered brown noise on a slow scrape
function drag(slow){
  const t = ctx.currentTime, src = ctx.createBufferSource();
  src.buffer = brownNoise; src.loop = true;
  const bp = ctx.createBiquadFilter(); bp.type = 'bandpass'; bp.Q.value = 0.9;
  bp.frequency.setValueAtTime(280, t);
  bp.frequency.exponentialRampToValueAtTime(170, t + 0.25 + 0.4*slow); // the scrape
  const g = ctx.createGain(), dur = 0.18 + 0.5*slow;
  g.gain.setValueAtTime(0, t);
  g.gain.linearRampToValueAtTime(0.16*(0.5+0.5*slow), t + 0.04);
  g.gain.exponentialRampToValueAtTime(0.0008, t + dur);   // settle into silence
  src.connect(bp).connect(g).connect(master);
  src.start(t); src.stop(t + dur + 0.05);
}

// pace: the gap since the last move decides how full the sound is
function paced(){
  const now = performance.now(), dt = now - last; last = now;
  if (dt < 70) return;                       // moving too fast → stay quiet
  const slow = Math.min(Math.max((dt-90)/900, 0), 1); // rushing → 0, lingering → 1
  drag(slow);                                  // slower hands get a fuller drag
}

In production, swap the synthesis for real buffers — ctx.decodeAudioData() on short recordings of the actual box, costume, and breath from the show — keeping the same envelopes, pace logic, and master chain.

D · Sound principles

Quiet, optional, never the only signal.

↳ 01

Off until asked

Nothing plays until the visitor enables sound — browser policy, yes, but also the ethic: silence is the default state of this stage.

↳ 02

Sound never carries meaning alone

Every audio cue rides alongside a visible state. A muted visitor misses nothing; the sound is atmosphere, not information.

↳ 03

Answers to pace, refuses clutter

Fast, repeated moves are throttled and ducked. The faster you go, the quieter it gets — the opposite of a notification.

↳ 04

Gentle by construction

Low gains, a soft lowpass, and a compressor across the master bus. No sharp transients, nothing that could startle.

A note on wellbeing: some visitors find sudden sound distressing. Beyond the toggle and volume, the concept honours prefers-reduced-motion as a hint to keep audio off until explicitly enabled.
