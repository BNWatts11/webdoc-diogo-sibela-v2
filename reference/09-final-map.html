B · Interaction logic

How a single box becomes a collective image.

01

One gesture

A click or tap drops a single box from where the visitor touched. That's the whole interaction — nothing to learn.

02

It finds its place

The box falls and settles onto the pile, leaning to the slope of whatever is already beneath it. No two land the same.

03

Density becomes light

Where many have placed boxes, overlaps stack and brighten; sparse areas stay dim. The crowd's weight shows as glow.

04

Traces persist, then haze

Older marks soften into the projection over time — present but dissolving, so the image is always of now, made of everyone.

C · Implementation guide

Two ideas do the work.

A cheap heightfield gives stacking and lean without a physics engine; additive compositing against a slow fade gives the long-exposure glow where the crowd overlaps.

// 1 · the pile is a heightfield — one number per column of the room
function settle(box){
  const [c0, c1] = columnsUnder(box);
  let top = 0;
  for (let c = c0; c <= c1; c++) top = Math.max(top, height[c]);   // rest on the tallest
  box.y = floor - top - box.h/2;
  box.angle = Math.atan((height[c1]-height[c0]) / box.w) * 0.6;       // lean to the slope
  for (let c = c0; c <= c1; c++) height[c] = top + box.h*0.6;        // the pile grows
}

// 2 · slow exposure — fade the whole room a touch, then add light back
function frame(){
  ctx.globalCompositeOperation = 'source-over';
  ctx.fillStyle = 'rgba(26,21,16,0.07)'; ctx.fillRect(0,0,W,H);   // the haze
  ctx.globalCompositeOperation = 'lighter';                          // overlaps brighten
  for (const b of boxes) drawBox(b, 0.05);   // equilibrium glow ∝ how many overlap here
  requestAnimationFrame(frame);
}

For real collective state, each placed box is a tiny record — { x, size, seed, t } — appended to a shared store and streamed back to every visitor. The room rebuilds the same pile from the same list, so two people on opposite sides of the world add to one image.

D · Principles

Collective, not competitive.

↳ 01

No scores, no ranking

Every trace is equal and anonymous. The reward is contribution to a shared image, never a number that compares people.

↳ 02

Accretive, never destructive

You can add but not delete others' boxes. The map only ever grows softer and denser — like a room filling with light.

↳ 03

Beautiful at any density

One box alone is a quiet mark; ten thousand is a luminous drift. The composition reads as art at every scale.

↳ 04

Accessible to leave

A “Leave a trace” button mirrors the click for keyboard and assistive tech; reduced-motion places boxes without the fall.
